# Условия использования — CueMe Content Studio

CueMe Content Studio — личный инструмент для создания коротких видео в формате
«переписки» с озвучкой. Приложение используется одним человеком (автором
проекта) и не предоставляется как публичный сервис третьим лицам.

## Интеграция с TikTok

Приложение может сохранять готовые видео как приватные черновики
(`privacy_level: SELF_ONLY`) в TikTok-аккаунт автора через официальный
TikTok Content Posting API. Черновик виден только автору внутри приложения
TikTok и не публикуется автоматически — публикация выполняется вручную,
самим автором, через приложение TikTok.

Приложение не публикует контент от имени других пользователей и не
запрашивает доступ к чужим TikTok-аккаунтам.

## Отказ от ответственности

Инструмент предоставляется «как есть», без гарантий. Автор не несёт
ответственности за контент, созданный или опубликованный с его помощью.
