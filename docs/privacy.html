Политика конфиденциальности — CueMe Content Studio

CueMe Content Studio — личный инструмент, не публичный сервис. Данные других пользователей не собираются и не обрабатываются.

Какие данные используются

  • Текст переписки, темы оформления и настройки макета, которые автор вводит сам, чтобы собрать видео — хранятся локально в браузере автора и на его собственном сервере во время рендера видео.
  • Аудио, сгенерированное через ElevenLabs API, — по запросу автора, для озвучки сообщений.
  • Токены доступа TikTok (access/refresh token), полученные через OAuth 2.0 после того, как автор сам подключает свой TikTok-аккаунт, — хранятся зашифрованными на сервере автора и используются только для загрузки видео как приватного черновика (SELF_ONLY) в аккаунт автора.

Как используются данные TikTok

Доступ к TikTok API используется исключительно для того, чтобы загрузить готовое видео в TikTok-аккаунт автора как приватный черновик. Приложение не публикует контент автоматически, не читает и не собирает данные о других пользователях TikTok, не передаёт данные третьим лицам.

Хранение и удаление

Автор может в любой момент отключить доступ приложения к своему TikTok-аккаунту — сохранённые токены при этом удаляются с сервера.
