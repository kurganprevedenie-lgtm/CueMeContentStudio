CueMe Content Studio

Личный инструмент для создания коротких видео в формате «переписки» с озвучкой. Компаньон-продукт к Telegram-боту CueMe.

Приложение может сохранять готовые видео как черновики во «Входящие» TikTok-аккаунта автора через официальный TikTok Content Posting API — черновик виден только автору и публикуется вручную через приложение TikTok.
