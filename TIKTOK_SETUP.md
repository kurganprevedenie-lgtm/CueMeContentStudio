# Как подключить свой TikTok-аккаунт к CueMe Content Studio

## Важно понять сразу

Приложение хранит подключение к TikTok на диске того компьютера/сервера, где оно запущено — по одному аккаунту за раз (см. `apps/web/lib/tiktokTokenStore.ts`, `apps/web/.data/tiktok-tokens.enc`). Поэтому:

- Если используешь **свою копию проекта** (свой `git clone`, свой `.env`) — просто следуй шагам ниже.
- Подключиться к **уже работающему у кого-то другого** приложению не получится — там место уже занято чужим аккаунтом. Нужна отдельная копия проекта.

## Шаг 0 — Поднять проект у себя

```bash
git clone <ссылка-на-репозиторий>
cd cueme-content-studio
pnpm install
cp .env.example .env
```

Понадобится Node.js 18+ и pnpm.

## Шаг 1 — Завести аккаунт в TikTok for Developers

1. Зайти на [developers.tiktok.com](https://developers.tiktok.com/) и авторизоваться обычным TikTok-аккаунтом (тем же, куда будешь заливать видео).
2. Раздел **Manage apps** → **Create app**.
3. Заполнить название приложения (любое, например `CueMe Studio Dev`), категорию — что-то близкое к "video/content".

## Шаг 2 — Подключить нужный продукт

В настройках приложения (**Add products**) добавить **Content Posting API** — именно он отвечает за загрузку видео. После добавления TikTok покажет `Client key` и `Client secret` — они понадобятся позже, но пока приложение находится в статусе разработки (не прошло App Review), и это нормально: часть функций (черновик во «Входящие») работает и без review.

## Шаг 3 — Настроить Redirect URI

В настройках Content Posting API (или общих настройках приложения) есть поле **Redirect URI** — туда нужно вписать **ровно**:

```
https://localhost:3000/api/tiktok/callback
```

Важно: именно `https`, не `http` — TikTok не пускает даже localhost по обычному http. Значение должно совпадать посимвольно с тем, что будет в `.env` (см. ниже).

## Шаг 4 — Sandbox и тестовые пользователи (если приложение ещё не прошло review)

Пока приложение в статусе разработки, авторизоваться через него могут только аккаунты, добавленные как **тестовые пользователи (target users)** в разделе Sandbox/Testers настроек приложения.

1. Найти в дашборде приложения раздел **Sandbox** → **Target Users** (или Testers).
2. Добавить туда свой TikTok username.
3. Подтвердить запрос, который придёт в приложении TikTok на телефоне.

Без этого шага при попытке войти TikTok просто откажет в авторизации.

## Шаг 5 — Заполнить `.env`

Открыть `.env` в корне проекта и вписать:

```bash
TIKTOK_CLIENT_KEY=<Client key из шага 2>
TIKTOK_CLIENT_SECRET=<Client secret из шага 2>
TIKTOK_REDIRECT_URI=https://localhost:3000/api/tiktok/callback
TIKTOK_PUBLISH_MODE=inbox
```

Отдельно сгенерировать ключ шифрования токенов (одна команда в терминале, значение вставить в `.env`):

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

```bash
TOKEN_ENCRYPTION_KEY=<результат команды выше>
```

## Шаг 6 — Запустить с HTTPS

TikTok требует https даже локально, поэтому запускать нужно не обычным `pnpm dev`, а:

```bash
pnpm --filter web dev:https
```

Это поднимет Next.js с самоподписанным сертификатом. Браузер при первом заходе на `https://localhost:3000` покажет предупреждение «соединение не защищено» — это ожидаемо (сертификат самоподписанный), нужно нажать «Всё равно перейти» / «Advanced → Proceed».

## Шаг 7 — Подключить аккаунт в интерфейсе

1. Открыть `https://localhost:3000`, дойти до готового видео (после экспорта .mp4) — там появится блок TikTok с кнопкой **«Подключить TikTok»**.
2. Нажать — откроется страница логина TikTok, войти своим аккаунтом (тем же, что добавлен тестером на шаге 4), подтвердить разрешения.
3. TikTok вернёт обратно в приложение — если всё прошло успешно, кнопка сменится на «Отправить видео в TikTok».

## Два режима публикации — что выбрать

В `.env` есть `TIKTOK_PUBLISH_MODE`, по умолчанию `inbox`:

| Режим | Что происходит | Нужен ли app review |
|---|---|---|
| `inbox` (по умолчанию) | Видео приходит **уведомлением** в TikTok — открыть и опубликовать вручную. В профиле и черновиках не видно, только по уведомлению | Нет |
| `direct` | Видео сразу попадает в профиль с видимостью **«Только я»** — опубликовать для всех можно вручную в приложении TikTok | Нет в Sandbox, но в production нужен пройденный App Review |

Публичной автоматической публикации нет ни в одном режиме — это осознанное ограничение проекта, TikTok такое разрешает только после серьёзного review с демо-видео.

Если меняешь `TIKTOK_PUBLISH_MODE` в `.env` — нужно **переподключить TikTok** заново (нажать «Отключить», потом снова «Подключить») — у токена, выданного под старый режим, не хватит разрешений.

## Частые проблемы

- **«code_challenge» ошибка при входе** — обычно означает, что redirect URI в `.env` не совпадает с тем, что вписан в дашборде TikTok. Сверить посимвольно.
- **Браузер ругается на сертификат** — нормально для `dev:https`, просто подтвердить переход.
- **После входа TikTok ничего не пускает / "not approved"** — забыли добавить себя в Target Users в Sandbox (шаг 4).
- **«Режим публикации изменился — переподключите»** — сменили `TIKTOK_PUBLISH_MODE`, нужно отключить и подключить TikTok заново.
